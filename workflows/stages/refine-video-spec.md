# Refine Video Spec

Opt-in stage only. Create Video normally writes and audits
`video_spec.md` and `video_lock.md`, then proceeds. If the user explicitly asks
to see/edit the complete production plan first, this stage inserts one blocking
review boundary after the spec audit and before the lock.

1. Present the actual `video_spec.md` from disk through the project's
   interactive review page when available; otherwise show the file or a
   concise, faithful summary in chat.
2. Stop and wait for explicit approval or revisions. Accept any number of
   user-led revision rounds. Do not ask a fixed questionnaire or score the
   creative plan.
3. Apply direct edits/comments to that one file and reconcile their dependent
   story, evidence, timeline, assets, and acceptance criteria. Do not rebuild
   unaffected sections or silently weaken a confirmed decision.
4. Once approved, write/resynchronize `video_lock.md`, validate both against the
   final retained confirmation, then resume Create Video at the lock checkpoint.

Never write or use the final lock before approval. If the user changes the
approved treatment, return to the owning confirmation gate rather than
pretending a local note can override it.
