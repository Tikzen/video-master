## CRITICAL: Visual Diversity Mandates

**These are REQUIREMENTS, not suggestions. Violation means the video fails quality review.**

### Scene-to-Scene Diversity (MV/Showcase Routes)

For videos with 3+ scenes:

1. **NO shared background systems across all scenes**
   - ❌ FORBIDDEN: All scenes using same grid system or atmosphere layers
   - ✅ REQUIRED: Each scene must have FUNDAMENTALLY DIFFERENT visual foundation
   - Example: Scene 1 = geometric shapes, Scene 2 = particle fields, Scene 3 = fluid forms, Scene 4 = architectural perspective

2. **Material variety mandate**
   - Every video MUST use at least 3 different material systems:
     - Gradient fills (linear/radial, multi-stop)
     - Glow/bloom on key elements
     - Extrusion (2.5D depth)
     - Glass/translucent layers
     - Additive blending for light
   - Run automated check: grep material declarations

3. **Visual complexity progression**
   - Scene density must vary: sparse intro → dense mid → focused climax → resolved end
   - At least one scene ≤15 layers, one scene ≥30 layers

4. **Lighting as narrative**
   - Each scene needs DIFFERENT lighting:
     - Directional beams / Radial bloom / Rim lighting / Volume particles / Beat-synced sweeps
   - Explicit light-source layers required

5. **Transition creativity**
   - ❌ FORBIDDEN: Only flow/iris/zoom primitives
   - ✅ REQUIRED: Object continuity, camera motivation, morphs, or justified cuts

## Pre-Generation Self-Check

Before writing build-plan.mjs:
